Task-Based Allocation: Model Evaluation
Phase 1: Testing Model Performance
Overview

The purpose of Phase 1 of the Task-Based Allocation project is to evaluate and compare different models to determine which one performs the best in terms of task similarity and accuracy. The best-performing model will then be used to assign tasks to the most suitable individuals, ensuring more efficient and accurate task allocation.
Objective

    Evaluate Multiple Models: We are testing various models, including CodeBERT, to compare their performance in determining task similarity.

    Task Allocation: The selected model will help us make data-driven decisions about assigning tasks to individuals based on task descriptions and code similarities.

    Optimize Efficiency: By identifying the best-performing model, we aim to optimize the process of task assignment and improve team productivity.
